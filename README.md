# Flask Medicine Application

Gyógyszer és javaslat kezelő alkalmazás Flask és MongoDB használatával.

## Funkciók

- Felhasználói regisztráció és bejelentkezés
- Gyógyszerek kezelése (hozzáadás, szerkesztés, listázás)
- Javaslatok kezelése (hozzáadás, szerkesztés, listázás)
- Védett útvonalak
- Reszponzív felület
- Modális ablakok dinamikus betöltése

## Technológiák

- Python 3.8+
- Flask
- MongoDB
- Flask-MongoEngine
- Flask-Login
- Flask-WTF
- Bootstrap 5
